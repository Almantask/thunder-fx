# A/B wording tests

Paired prompts for testing **prompt wording on beds**, one variable at a time. Every pair
is an `(A)` and a `(B)` that differ in exactly one thing; duration and the `Negative:` line
are held fixed across the pair.

Beds answer these questions differently from one-shots — a word that sharpens a door slam
can flatten a rain bed — so run the [FX set](../fx/ab-wording.md) and this one before
generalising any rule. Judge these on steadiness and loop seams, not on impact.

Run on **Balanced**, fix the seed, queue both halves, then **Compare** the two clips.
Two seeds minimum per pair, and require both to agree.

To queue one pair, type its tag (`W19`, `W24`, …) into the **Browse prompts** search box and
press **Add visible**. That queues exactly that pair and nothing else.
