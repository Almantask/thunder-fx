# Prompt catalog

Shipped starting prompts for **Browse prompts** on Generate. Two libraries:

- [Sound effects](fx/README.md) — game one-shots (`TrackType: SFX`)
- [Ambience](ambience/README.md) — D&D instrumental beds (`TrackType: Music`), adapted from Sunder for Stable Audio 3 Medium

The Browse prompts dialog lists each library separately so Combat sound effects and Combat music stay distinct.
